| 32  | Admin lockout (strict) | Counted across all wrong tries (password, emailed code, reset code) since the last successful sign-in: first 2 wrong = warning with attempts left; 3rd wrong = blocked 15 minutes; 4th wrong = 1 hour; 5th and later = 1 day.
